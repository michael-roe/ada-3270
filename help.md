# Using Help

## Function Keys

The following function keys are available in Help panels:

F1 = Help (for Help): Provides information about using the Help system.

F2 = Extended Help : Provides an overview of the application.

F3 = Exit : Exits the Help system and returns to the panel from which
Help was invoked.

F7 = Prev : Scrolls up the contents of the Help panel.

F8 = Next : Scrolls down the contents of the Help panel.

F9 = Keys Help : Shows a list of function keys and their functions.

F11 = Help Index : Shows an index of Help topics.

F12 = Cancel : Returns to the panel from which Help was invoked.
